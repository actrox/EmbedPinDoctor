# STM32F103C8T6 接线规划报告

- 项目名称：p5_http_verify
- 项目备注：P5 HTTP 验证

## 项目信息

- 芯片：STM32F103C8T6
- IO 电压：3.3V
- 模块数量：5

## 模块清单

- OLED I2C 屏幕：常见 0.96 寸 I2C OLED 显示屏
- MPU6050 姿态传感器：I2C 六轴姿态传感器，可选中断引脚
- 普通按键：单个 GPIO 按键输入
- 蜂鸣器：有源或无源蜂鸣器控制信号
- SD 卡模块：SPI 模式 SD 卡模块

## 接线表

| 模块 | 模块引脚 | 芯片引脚 | 功能 | 说明 |
| --- | --- | --- | --- | --- |
| OLED I2C 屏幕 | SCL | PB6 | I2C1_SCL | I2C 时钟线 |
| OLED I2C 屏幕 | SDA | PB7 | I2C1_SDA | I2C 数据线 |
| MPU6050 姿态传感器 | SCL | PB6 | I2C1_SCL | 与 OLED 共用 I2C 时钟 |
| MPU6050 姿态传感器 | SDA | PB7 | I2C1_SDA | 与 OLED 共用 I2C 数据 |
| MPU6050 姿态传感器 | INT | PA0 | EXTI | 姿态数据中断输入 |
| 普通按键 | KEY | PA1 | GPIO | 建议配合上拉或下拉电阻 |
| 蜂鸣器 | SIG | PA2 | PWM | 无源蜂鸣器建议使用 PWM 引脚 |
| SD 卡模块 | SCK | PA5 | SPI1_SCK | SPI 时钟 |
| SD 卡模块 | MISO | PA6 | SPI1_MISO | SPI 主入从出 |
| SD 卡模块 | MOSI | PA7 | SPI1_MOSI | SPI 主出从入 |
| SD 卡模块 | CS | PA3 | GPIO | 片选引脚，多个 SPI 设备不可共用 |

## 风险报告

- [提示] OLED I2C 屏幕 使用 I2C，请确认 SDA/SCL 已有合适上拉电阻。
  - 建议：检查模块板载电阻，并根据总线长度和速率计算等效上拉。
- [提示] MPU6050 姿态传感器 使用 I2C，请确认 SDA/SCL 已有合适上拉电阻。
  - 建议：检查模块板载电阻，并根据总线长度和速率计算等效上拉。

## 后续建议

1. 画原理图前，确认所有启动脚和调试脚没有被高风险外设占用。
2. 对 I2C 总线确认上拉电阻，对 SD 卡等模块确认 3.3V 电平兼容。
3. 固件项目中保持接线表和引脚定义文件同步更新。
