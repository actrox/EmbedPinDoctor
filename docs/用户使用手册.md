# EmbedPinDoctor 用户使用手册

## 1. 启动

在项目根目录执行：

```bash
python start_embedpindoctor.py
```

然后打开：`http://127.0.0.1:8765`

Windows 用户也可以双击 `start_embedpindoctor.bat`。

## 2. 基本流程

1. 输入项目名称。
2. 选择芯片。
3. 在模块库中勾选模块。
4. 点击“自动分配”。
5. 查看右侧风险报告和处理建议。
6. 必要时手动修改芯片引脚。
7. 点击“按当前表格重新检查”。
8. 保存项目或导出结果。

## 3. 常用导出

- Markdown：接线表、模块清单、风险报告和项目备注。
- `pins.h`：基础 C/C++ 引脚定义。
- Arduino、STM32 HAL、ESP-IDF：对应平台的引脚模板。
- KiCad 标签：用于原理图网络标注整理。
- PlatformIO：生成 `platformio.ini`、`src/main.cpp` 和 `include/pins.h`。
- IOC 片段：生成 STM32CubeMX 辅助配置文本。

## 4. 风险处理原则

- “错误”必须处理后再进入原理图设计。
- “警告”需要对照芯片手册和模块资料确认。
- “提示”是设计检查提醒，不代表一定存在故障。
- 软件输出不能替代芯片数据手册、原理图审查和实物电气测试。

## 5. 项目文件

- 项目保存于 `projects/`。
- 导出结果位于 `output/`。
- 芯片库位于 `data/chips/`。
- 模块库位于 `data/modules/`。
- 规则包位于 `rule_packs/`。
