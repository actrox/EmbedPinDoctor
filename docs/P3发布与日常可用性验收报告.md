# P3 发布与日常可用性验收报告

## 完成范围

- 项目文件 schema 升级到 v2，兼容旧版 `chip` / `modules` 字段并在打开时自动迁移。
- 保存采用同目录临时文件、落盘同步和原子替换，避免异常中断留下半个 JSON。
- 每个项目保留最多 30 个版本，支持跨重启撤销与重做。
- 启动器自动选择可用端口，等待健康检查成功后才打开浏览器。
- 日志按 2 MiB 轮转并记录主线程、工作线程和 HTTP 请求异常。
- 诊断包默认不携带项目文件；只有显式选择时才包含用户项目数据。
- 提供 PyInstaller Windows 单文件配置、构建脚本、发布目录校验器和 GitHub Actions 回归矩阵。

## 数据位置

源码运行时仍使用仓库内的 `projects`、`output` 和 `logs`。Windows 单文件运行时，项目、输出和日志写入 `%LOCALAPPDATA%\EmbedPinDoctor`，打包资源保持只读。

## 验收命令

```powershell
python run_tests.py
python -m quality.data_audit
node --check web/app.js
python -m PyInstaller --noconfirm --clean release\EmbedPinDoctor.spec
```

最后一项是发布机上的实际构建命令；日常回归不强制安装 PyInstaller。
