# P4 数据与插件生态验收报告

## 完成范围

- 统一支持 `data`、`rules`、`plugin` 三类本地生态包。
- 校验包 ID、SemVer、最低应用版本、文件集合、硬件数据 Schema 和可选 SHA-256。
- 安装采用先完整校验、再暂存、最后原子替换的流程；失败时恢复已提交文件。
- 覆盖文件在包注册表旁保存备份，卸载时恢复原文件；新增文件则安全删除。
- 默认拒绝降级，可由调用方显式允许；插件支持启用和停用，数据与规则通过卸载停用。
- 插件 capability 使用白名单，损坏插件被隔离显示，不影响其他插件发现。
- Web 工作台提供本地扩展包路径、安装、启停和卸载入口。

## 生态包清单示例

```json
{
  "id": "vendor.sensor-pack",
  "name": "Sensor Pack",
  "version": "1.2.0",
  "type": "data",
  "min_app_version": "0.1.0-alpha.8",
  "checksums": {
    "modules/example.json": "<sha256>"
  }
}
```

`checksums` 一旦提供，必须完整覆盖包内所有可安装文件。

## 安全边界

P4 插件是声明式能力注册，不会直接执行扩展包中的任意脚本。后续若开放可执行插件，需要单独设计进程隔离、权限授权和签名信任链。
