# P1 真实项目扫描验收报告

## 目标

让 EmbedPinDoctor 从“根据手动选择规划新项目”扩展为“只读扫描现有嵌入式工程”，识别工程类型、主控与引脚来源，并比较固件、配置、原理图和医生建议之间的差异。

## 安全限制

- 不跟随目录符号链接。
- 跳过 `.git`、构建目录、依赖目录和虚拟环境。
- 最多扫描 2000 个候选文件。
- 单个文本文件最大 2MB。
- 只解析白名单扩展名。
- 不执行项目脚本、构建命令或工程中的任何代码。

## 当前兼容范围

- PlatformIO：`platformio.ini` 与 C/C++ 代码。
- Arduino：`.ino`、头文件和 C/C++ 文件。
- ESP-IDF：`sdkconfig`、组件 CMake 和 `GPIO_NUM_x` 宏。
- STM32CubeMX：`.ioc`、`GPIOx`/`GPIO_PIN_x` 组合宏。
- KiCad：XML `.net` 网表，以及 `名称 引脚` 格式的标签文本。

KiCad `.kicad_sch` 的完整原理图语义解析不在本阶段承诺范围内；该文件用于工程识别，精确 MCU 网络映射优先使用 KiCad 网表。
