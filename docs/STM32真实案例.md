# STM32F103C8T6 真实案例

## 目标

验证 EmbedPinDoctor 对常见原型板组合的规划能力：STM32F103C8T6、OLED I2C 屏幕、MPU6050、普通按键、蜂鸣器和 SD 卡模块。

## 推荐操作

在界面中选择 `STM32F103C8T6`，勾选上述五个模块并点击自动分配。

预期会得到：

- OLED 与 MPU6050 共用 I2C1。
- MPU6050 的 INT 使用 EXTI 输入。
- 蜂鸣器使用 PWM 能力引脚。
- SD 卡使用 SPI1，并单独分配 CS。
- I2C 上拉提醒。

## 人工审核清单

1. 对照 STM32F103C8T6 官方数据手册核对 PA/PB 复用功能。
2. 确认 PA13 / PA14 没有被外设占用，以保留 SWD。
3. 确认 PB2 启动相关属性没有被外部电路改变。
4. 确认 OLED 和 MPU6050 的 I2C 地址没有冲突。
5. 确认 I2C 总线实际等效上拉阻值。
6. 确认 SD 卡模块是 3.3V 逻辑，必要时增加电平转换。
7. 确认蜂鸣器电流不超过 GPIO 驱动能力，必要时增加三极管。
8. 上电、复位、下载、运行四种状态分别测试。

只有完成上述人工审核和实物测试，才能把生成结果用于正式 PCB 设计。
