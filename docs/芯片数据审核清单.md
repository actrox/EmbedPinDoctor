# 芯片数据审核清单

每个芯片数据文件进入正式库前，需要完成以下审核：

- [ ] 芯片型号和封装正确。
- [ ] 所有可用 GPIO 名称正确。
- [ ] ADC 通道映射已核对。
- [ ] PWM / 定时器映射已核对。
- [ ] UART、SPI、I2C 复用已核对。
- [ ] SWD/JTAG 调试脚已标记。
- [ ] Boot / 启动相关引脚已标记。
- [ ] 上电默认电平和输入输出限制已记录。
- [ ] IO 电压和容忍度已记录。
- [ ] 特殊复用和重映射限制已记录。
- [ ] 至少编写一个自动分配测试。
- [ ] 至少编写一个风险检查测试。
- [ ] 由第二人或第二份资料复核。
